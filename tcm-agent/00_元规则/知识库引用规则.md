# 知识库引用规则

## 目的

本规则规范知识库引用的格式和原则，确保回答有据可查，同时避免编造、误引或过度引用。

---

## 引用原则

### 原则一：有所依则引，无依据则明

- **必须引用**：回答中方药分析、证型判断、病机解释等关键内容，如有知识库依据，必须引用
- **无依据则明说**：如果某个观点没有找到知识库依据，必须明确写"当前知识库未检索到直接依据"
- **禁止编造**：绝对不得编造经典原文、条文编号或医案来源

### 原则二：引用准确，不篡改原意

- 引用原文时，应尽量保留原文完整语义，不得断章取义
- 如需节录，必须保留核心词句，不得改变原意
- 解释原文时，应基于知识库中的解释或公认的传统理解，不得加入现代医学解释作为主要依据

### 原则三：引用层次清晰

- 经典原著（《伤寒论》《金匮要略》《黄帝内经》等）优先引用
- 后世注释家观点（胡希恕、成无己等）次之
- 现代研究仅作参考，不作为主要依据
- 方药分析以经典原文为主要依据

### 原则四：多来源印证

- 重要判断应尽量有多于一个知识库来源印证
- 如只有一个来源，需注明"该观点仅来自单一来源，待补充"
- 来源之间如有矛盾，应说明差异，不强行统一

## 引用格式规范

### 标准引用格式

```markdown
## 知识库引用

- **《伤寒论》・第X条**：[简要说明引用内容与当前问题的关系]
- **《金匮要略》・XX病脉证治第X篇**：[同上]
- **《黄帝内经》・素问/灵枢・XX篇**：[同上]
- **《脾胃论》・卷X**：[同上]
- **《胡希恕经方理论与实践》**：[说明观点来源]
```

### 条文引用格式

```markdown
**来源**：《伤寒论・辨太阳病脉证并治上》  
**条文**：第X条  
**原文**：  
> [原文]  
**释义**：[简要解释该条文的核心含义]
```

### 多条文印证格式

```markdown
### 经典依据

**依据一**  
- 来源：《伤寒论》第X条  
- 原文："[原文]"  
- 要点：说明了……

**依据二**  
- 来源：《金匮要略・XX病证》  
- 原文："[原文]"  
- 要点：从XX角度补充了……

**综合说明**：[综合两个来源的要点，说明判断依据]
```

## 各类内容的引用规则

### 方剂来源引用

每个方剂至少引用一个经典来源：

```markdown
## 经典依据

**来源**：《伤寒论》・辨太阳病脉证并治中  
**条文**：第X条  
**原文**：  
> "[方剂组成和适应证的原文]"  
**说明**：[该条文如何定义方剂的主治和组成]
```

如知识库无该方剂的直接依据：

```markdown
## 经典依据

当前知识库未检索到[方剂名]的经典原文记载。

[可选：说明该方的后世出处或公认来源]
```

### 药物功效引用

```markdown
## 药物功效依据

**[药物名]**：  
- 来源：《黄帝内经》/《神农本草经》/《本草纲目》等  
- 记载："[原文]"  
- 功效解释：[传统解释]

如无依据：
**[药物名]**：当前知识库未检索到该药物的经典功效记载。
```

### 证型判断引用

```markdown
## 证型依据

**证型名**：太阳表虚证  

**经典依据**：
1. 《伤寒论》第2条："太阳病，发热，汗出，恶风，脉缓者，名为中风。"
2. 《伤寒论》第12条："太阳中风，阳浮而阴弱……"

**病机解释**：上述条文说明太阳表虚证的病机是……
```

### 症状分析引用

```markdown
## 症状经典依据

**症状**：饭后胃胀  

**古代论述**：
- 来源：《素问・阴阳应象大论》："饮食自倍，肠胃乃伤。"
- 来源：《脾胃论》："脾虚则气短，精神少，倦怠乏力。"

**现代理解**（仅供参考）：[不作为主要依据]
```

## 禁止的引用行为

### 绝对禁止

1. **编造原文**：不得编造"《伤寒论》第X条说……"
2. **篡改原意**：不得用现代观念曲解经典原文
3. **虚假来源**：不得声称来自某书而实际无此出处
4. **过度引用**：不得堆砌大量无直接关系的引用来"撑场面"
5. **唯一依据**：不得将后世发挥当作经典原文引用

### 谨慎使用

1. **孤证不立**：单一来源的判断需注明局限性
2. **学派差异**：不同学派对同一问题可能有不同解释，应客观呈现，不强加一致
3. **现代研究**：现代药理研究仅作参考，不得作为方药决策的主要依据

---

## 引用缺失时的处理

当知识库无法找到直接依据时，必须使用以下表述之一：

### 表述一：完全无据

```markdown
**经典依据**：当前知识库未检索到直接依据，该判断基于[后世医家名/经验/推理]。
```

### 表述二：有近似依据但非直接

```markdown
**经典依据**：当前知识库未检索到直接条文，但类似观点见于：
- 《XX》・[章节]："[相关内容]"
（该记载与当前问题近似，但不完全对应）
```

### 表述三：有间接依据

```markdown
**经典依据**：当前知识库未检索到该观点的直接出处，但可从以下条文间接理解：
- 《XX》・[章节]提到……，可作为辅助理解。
```

## 引用自检清单

每次引用后，自查以下问题：

- [ ] 该原文是否真实存在于知识库中？
- [ ] 该引用是否准确反映原文含义？
- [ ] 该引用与当前分析是否直接相关？
- [ ] 是否标注了所有知识库未涵盖的判断？
- [ ] 是否避免了编造和篡改？

```markdown
### 引用声明

本回答中的经典引用来自本地中医知识库，引用内容力求准确，但可能存在：
- 文本理解偏差
- 引用格式不严格
- 知识库收录不完整

如对引文准确性有疑问，请查阅原文或咨询专业人员。
```
