# 方药回答模板

## 概述

本模板规范所有方药类问题的回答格式，确保信息完整、风险提示充分、引用有据、AI判断声明明确。

---

## 通用格式要求

### 标题格式
```
# 方药分析：[用户主诉/问题核心]
```

### 开头风险声明
所有方药分析回答，开头必须包含：

```markdown
> ⚠️ 本分析仅供参考，不能替代专业中医师诊断。如有急症、长期慢病、正在用药，请就医。
```

---

## 通用声明格式

每种格式末尾必须包含相应风险级别的声明。所有格式均需在结尾包含：

```markdown
## AI判断声明

以上分析是AI基于本地中医知识库作出的方药辨证推演，可能存在以下局限：
- 信息完整度不足导致的判断偏差
- 知识库文本理解偏差
- 未考虑个体差异和复杂病情
- 知识库尚未收录的相关论述

方药使用涉及诊断、剂量、炮制、配伍、禁忌、现用药冲突和疗程调整，最终是否适合服用、如何加减、剂量和疗程，应由专业中医师结合面诊、舌脉和病史综合判断。

如有急症、严重不适或正在使用其他药物，请立即就医。
```

## 快速参考：各格式声明强度

| 格式类型 | 声明强度 | 说明 |
|---------|---------|-----|
| 格式一（方证分析） | 中 | 有方有据，需专业指导 |
| 格式二（症状选方） | 高 | 涉及选方用药，谨慎程度高 |
| 格式三（药食同源） | 低 | 材料相对安全，但需说明体质差异 |
| 格式四（鉴别比较） | 中 | 比较分析，仍需专业判断 |
| 格式五（高风险药物） | 极高 | 严禁自行使用，声明最强 |
