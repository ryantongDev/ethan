# 高风险药物名单

## 目的

本文件列出所有高风险药物，明确限制规则。所有涉及这些药物的分析必须遵循"高风险模式"，不得给出用户可直接执行的方案。

---

## 高风险药物分类

### 第一类：有大毒之药（严格禁用类）

以下药物毒性剧烈，未经炮制或剂量不当可致严重中毒或死亡：

| 药物名 | 主要毒性 | 风险说明 |
|-------|---------|---------|
| 川乌 | 乌头碱 | 生用致死量低，炮制后仍需谨慎 |
| 草乌 | 乌头碱 | 同川乌 |
| 附子 | 乌头碱 | 炮制后可用，但剂量窗口窄，过量致心律失常 |
| 生半夏 | 草酸钙针晶 | 口腔咽喉刺激，生用有毒 |
| 生南星 | 同生半夏 | 毒性较强 |
| 斑蝥 | 斑蝥素 | 剧毒，外用亦需谨慎 |
| 雄黄 | 硫化砷 | 砷化物，不宜久服 |
| 朱砂 | 硫化汞 | 汞积累中毒 |
| 水银类 | 汞 | 严格禁用 |
| 马钱子 | 士的宁 | 过量致强直抽搐 |
| 巴豆 | 巴豆毒素 | 剧烈泻下，可致脱水休克 |

---

### 第二类：有毒但经炮制后可用（专业使用类）

以下药物经炮制后毒性降低，但仍有严格剂量和适应症限制，须由专业中医师判断：

| 药物名 | 炮制要求 | 风险说明 |
|-------|---------|---------|
| 制附子 | 蒸煮去毒 | 需先煎减毒，剂量不超过15g |
| 醋南星 | 矾浸麸炒 | 降低刺激性和毒性 |
| 姜半夏 | 姜矾煮 | 降毒后可用于经方 |
| 法半夏 | 石灰液浸 | 降毒后可用于经方 |
| 炙甘遂 | 醋炙 | 毒性降低，但仍需专业判断 |
| 炙大戟 | 醋炙 | 同上 |
| 炙芫花 | 醋炙 | 同上 |
| 制蜈蚣 | 去头足 | 减少毒性 |
| 制全蝎 | 去盐 | 减少刺激 |

---

### 第三类：药性峻烈（专业处方类）

以下药物无明显毒性，但药性峻烈，非专业辨证不可轻用：

| 药物名 | 峻烈程度 | 主要风险 |
|-------|---------|---------|
| 麻黄 | 发汗峻 | 过汗伤津，心悸失眠 |
| 细辛 | 散寒峻 | 过量伤气，动气上逆 |
| 大黄 | 泻下峻 | 伤津耗气，滥用致腹泻 |
| 芒硝 | 软坚泻下 | 伤津，孕妇忌用 |
| 桃仁 | 活血破瘀 | 动血，孕妇忌用 |
| 水蛭 | 破血逐瘀 | 出血风险，出血性疾病禁用 |
| 虻虫 | 破血逐瘀 | 同上，较桃仁更峻 |
| 土鳖虫 | 破血 | 同上 |
| 甘遂 | 逐水 | 剧烈泻下，虚弱者慎用 |
| 牵牛子 | 逐水消肿 | 泻下，孕妇禁用 |
| 蟾酥 | 强心毒 | 剂量难控，易中毒 |

## 高风险药物使用限制规则（高风险模式）

### 规则1：绝对禁止给出信息

对于"有大毒之药"（第一类），不得提供以下信息：
- ❌ 直接剂量（无论多少）
- ❌ 煎服方法
- ❌ 加减方案
- ❌ 具体疗程
- ❌ 用户自行使用的建议

### 规则2：仅可解释的信息

对于高风险药物，仅可提供以下说明：
- ✅ 该药物在经典方剂中的君臣佐使作用
- ✅ 经典原文中的方证逻辑
- ✅ 使用该药物时需要专业中医师判断
- ✅ 可能的中毒症状（用于提醒就医）
- ✅ 炮制减毒的基本原理
- ✅ 哪些体质或情况下严禁使用

### 规则3：触发条件

当分析涉及以下药物时，必须自动进入"高风险模式"：
- 附子
- 川乌、草乌
- 生半夏、生南星
- 斑蝥、蟾酥
- 雄黄、朱砂
- 水银类
- 马钱子、巴豆
- 甘遂、大戟、芫花
- 牵牛子
- 细辛（超量时）

### 规则4：高风险模式输出格式

当触发高风险模式时，分析结尾必须包含以下声明：

```markdown
## ⚠️ 高风险药物特别提示

**涉及药物**：附子（超出常规安全剂量范围）

**本知识库不对以下内容负责**：
- 任何自行去药店购买并使用该药物的行为
- 自行调整剂量的行为
- 自行与其他药物配伍的行为
- 未在专业中医师指导下使用的行为

**如需使用该药物**：
- 请到正规中医院就诊
- 由有经验的中医师开具处方
- 在药师指导下正确煎煮（先煎、久煎）
- 如出现口麻、头晕、心悸、恶心等中毒症状，立即停药并就医
```

### 规则5：关联保护

如果用户同时在用以下药物或情况，分析时必须额外提醒：
- 正在用降压药、降糖药、抗凝药
- 有肝肾功能异常
- 孕妇或哺乳期
- 儿童或老年人
- 有心脏病史

## 常见高风险药物配伍禁忌（供知识库引用，不得作为用户执行方案）

以下配伍禁忌来自经典记载，专业使用时应由中医师判断：

1. **十八反**：
   - 甘草反甘遂、大戟、海藻、芫花
   - 乌头反贝母、瓜蒌、半夏、白蔹、白及
   - 藜芦反人参、丹参、玄参、沙参、细辛、芍药

2. **十九畏**：
   - 硫黄畏朴硝，水银畏砒霜，狼毒畏密陀僧
   - 巴豆畏牵牛，丁香畏郁金，川乌、草乌畏犀角
   - 牙硝畏三棱，官桂畏石脂，人参畏五灵脂

（本知识库不推荐用户自行记忆或使用上述配伍，仅供中医师参考）
