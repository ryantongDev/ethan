# 经方适配评分规则

## 目的

本规则用于评估用户描述的症状/证型与候选经方之间的适配程度，输出量化评分供决策参考。

---

## 评分维度

适配评分从以下五个维度综合评估：

| 维度 | 权重 | 说明 |
|-----|-----|-----|
| 主症匹配 | 40% | 核心症状的符合程度 |
| 兼症匹配 | 15% | 次要症状的符合程度 |
| 寒热虚实匹配 | 20% | 寒热虚实表里的整体符合度 |
| 舌脉体质匹配 | 15% | 舌象、脉象、体质倾向的符合度 |
| 风险扣分 | 10% | 高风险药物带来的限制 |

---

## 评分标准（每项满分100分）

### 1. 主症匹配（满分100分，权重40%）

| 匹配程度 | 得分 | 说明 |
|---------|-----|-----|
| 完美匹配 | 100 | 用户描述与方剂主症高度一致，包括核心病机 |
| 基本匹配 | 75 | 主要症状对得上，但病机有细微差异 |
| 部分匹配 | 50 | 部分主要症状符合，但有明显缺失或矛盾 |
| 勉强匹配 | 25 | 只有1-2个主症对得上 |
| 不匹配 | 0 | 主症完全不符合 |

### 2. 兼症匹配（满分100分，权重15%）

| 匹配程度 | 得分 | 说明 |
|---------|-----|-----|
| 完美匹配 | 100 | 所有兼症均支持该方 |
| 基本匹配 | 75 | 兼症大部分支持，无明显矛盾 |
| 部分匹配 | 50 | 兼症有一些支持，有1-2个矛盾 |
| 不匹配 | 0 | 兼症与该方证矛盾 |

### 3. 寒热虚实匹配（满分100分，权重20%）

| 匹配程度 | 得分 | 说明 |
|---------|-----|-----|
| 完全一致 | 100 | 寒热、虚实、表里均一致 |
| 基本一致 | 75 | 寒热虚实基本一致，细节差异 |
| 部分一致 | 50 | 有1-2项不一致 |
| 矛盾 | 0 | 寒热或虚实根本对立 |

### 4. 舌脉体质匹配（满分100分，权重15%）

| 匹配程度 | 得分 | 说明 |
|---------|-----|-----|
| 完全一致 | 100 | 舌象、脉象、体质均高度符合 |
| 基本一致 | 75 | 舌脉基本符合，体质无明显冲突 |
| 部分一致 | 50 | 舌脉有1-2项不完全符合 |
| 缺乏信息 | 50 | 用户未提供舌脉，按符合处理 |
| 矛盾 | 0 | 舌脉与该方证明显矛盾 |

### 5. 风险扣分（满分-40分，权重10%）

| 风险情况 | 扣分 | 说明 |
|---------|-----|-----|
| 含高风险药物 | -40 | 含一类高风险药物 |
| 含二类高风险药物 | -20 | 仅含炮制后可用的有毒药 |
| 含峻烈药物 | -10 | 含药性峻烈之药 |
| 无高风险药物 | 0 | 均为常用药 |

---

## 综合评分计算

```
综合得分 = (主症得分×0.40 + 兼症得分×0.15 + 寒热虚实×0.20 + 舌脉体质×0.15 + 风险分×0.10)
```

**风险分计算**：
- 无风险药物：100分（不扣分）
- 有峻烈药物：90分（-10）
- 有二类高风险：80分（-20）
- 有一类高风险：60分（-40）

---

## 评分等级

| 综合得分 | 等级 | 含义 | 建议 |
|---------|-----|-----|-----|
| 85-100 | ★★★★★ | 高度适配 | 可作为首选推荐，但需专业确认 |
| 70-84 | ★★★★☆ | 较好适配 | 可作为备选，需观察用药反应 |
| 55-69 | ★★★☆☆ | 中等适配 | 可作为辅助，需结合其他治疗 |
| 40-54 | ★★☆☆☆ | 勉强适配 | 风险较高，仅专业判断后使用 |
| 0-39 | ★☆☆☆☆ | 不适配 | 不建议使用，建议更换方向 |

## 特殊情况的评分处理

### 信息不足时
当用户未提供舌象或脉象时：
- 该项按"缺乏信息"处理（得50分）
- 在评分说明中注明"因信息缺失，该项按50分处理"
- 综合得分标注"（参考）"

### 多种兼夹证时
当用户有多种证型兼夹时：
- 先分别评估各证型的适配分
- 综合判断时以主要矛盾为主
- 在评分说明中注明兼夹情况

### 风险因素一票否决
当方剂含一类高风险药物且用户属于以下情况时，直接判定为不推荐：
- 孕妇或哺乳期
- 儿童或70岁以上老人
- 有肝肾功能异常
- 正在使用可能相互作用的药物
- 用户主动要求自行用药

### 优先法则
1. **安全优先**：综合得分高但含高风险药物的方剂，不得优先于安全但得分略低的方剂
2. **主症优先**：主症匹配度权重最高，主症不匹配则大幅降低分数
3. **信息完整度**：信息越完整，评分越可靠；信息缺失时结论应更保守

## 评分局限性声明（必须包含）

```markdown
### 评分局限性说明

本评分系统有以下固有局限，输出评分时必须包含本声明：

1. **信息依赖**：评分结果高度依赖用户提供的信息完整度和准确性，信息不足时评分仅供参考
2. **文本理解局限**：知识库对经典条文的理解可能存在偏差，影响评分准确性
3. **个体差异**：评分未考虑体质、年龄、性别、病程长短等个体差异
4. **动态变化**：症状和证型可能随时间变化，评分反映的是当前时点的判断
5. **专业判断不可替代**：无论评分高低，最终用药决策必须由专业中医师做出

**评分不作为医疗建议，仅供学习参考和专业判断辅助。**
```
