# 太阳表实

## 基本信息
- 证型：太阳表实证
- 来源：《伤寒论》太阳病篇
- 所属体系：伤寒学派 · 六经辨证 · 太阳病
- 风险等级：中

## 证候表现
### 主症
- 恶寒发热
- 身疼痛
- 无汗
- 脉浮紧

### 兼症
- 头痛
- 腰痛
- 骨节疼痛
- 喘
- 舌淡红，苔薄白

### 典型条文
《伤寒论》第3条："太阳病，或已发热，或未发热，必恶寒、体痛、呕逆、脉阴阳俱紧者，名为伤寒。"

第35条："太阳病，头痛、发热、身疼、腰痛、骨节疼痛、恶风、无汗而喘者，麻黄汤主之。"

## 病机分析
- **病因**：寒邪袭表
- **病位**：太阳经、营分
- **核心病机**：卫阳被遏，营阴郁滞，肺气不宣
- **特点**：表实无汗、表证较重

## 辨证要点
| 要点 | 太阳表实（伤寒） | 太阳表虚（中风） |
|------|------------------|------------------|
| 发热 | 有（较重） | 有（翕翕发热） |
| 恶寒 | 恶寒重 | 恶风为主 |
| 汗出 | 无（身疼痛） | 有（汗自出） |
| 脉象 | 浮紧 | 浮缓 |
| 身疼 | 身疼腰痛剧烈 | 轻微 |
| 喘 | 无汗而喘 | 无或有 |

## 治法方药
- **治则**：发汗解表，宣肺平喘
- **主方**：麻黄汤
- **药物**：麻黄、桂枝、杏仁、甘草
- **服法**：温服取微汗，不须啜粥

## 适应证
- 恶寒发热、无汗、身疼痛、脉浮紧
- 流感初起属风寒表实
- 急性鼻炎属风寒
- 哮喘属寒邪束表

## 禁忌证
- 发热汗出、脉浮缓（桂枝汤证）
- 脉微弱（里虚）
- 尺中脉迟（营气不足）
- 咽喉干燥（津液不足）
- 疮疡、衄血、淋证患者
- 产后血虚外感

## 变证及治法
| 变证 | 主方 |
|------|------|
| 项背强急无汗 | 葛根汤 |
| 外寒内饮 | 小青龙汤 |
| 表寒里热烦躁 | 大青龙汤 |
| 传阳明 | 白虎汤 |
| 传少阳 | 小柴胡汤 |

## 预后
- 正确发汗可解
- 失治误治可传变
- 可逆转为少阴阳虚

## 风险提示
- 麻黄汤发汗力强，须中病即止
- 不可如水淋漓
- 高血压、心脏病患者慎用
