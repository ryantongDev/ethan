# 阳明里热

## 基本信息
- 证型：阳明里热证
- 来源：《伤寒论》阳明病篇
- 所属体系：伤寒学派 · 六经辨证 · 阳明病
- 风险等级：低

## 证候表现
### 主症
- 身大热
- 不恶寒，反恶热
- 大汗出
- 大渴引饮
- 脉洪大

### 兼症
- 面赤
- 心烦
- 舌红，苔黄燥
- 腹满痛（腑实证）

### 典型条文
《伤寒论》第182条："问曰：阳明病外证云何？答曰：身热、汗自出、不恶寒、反恶热也。"

第26条："服桂枝汤，大汗出后，大烦渴不解，脉洪大者，白虎加人参汤主之。"

## 病机分析
- **病因**：太阳病传变或直中阳明
- **病位**：阳明经（气分）或阳明腑（腑实）
- **核心病机**：邪入阳明，热盛津伤（经证：气分热盛；腑证：燥屎内结）
- **特点**：里热炽盛，不恶寒反恶热

## 经证与腑证鉴别
| 鉴别点 | 阳明经证 | 阳明腑证 |
|--------|----------|----------|
| 主症 | 四大症（大热、大汗、大渴、脉洪大） | 潮热、谵语、腹满痛、便秘 |
| 兼症 | 心烦、面赤 | 循衣摸床、四肢厥冷 |
| 舌象 | 舌红苔黄燥 | 舌红苔黄燥裂 |
| 脉象 | 洪大 | 沉实有力 |
| 治法 | 清热生津 | 泻下燥实 |

## 治法方药
### 经证
- **治则**：清热生津
- **主方**：白虎汤、白虎加人参汤
- **药物**：石膏、知母、甘草、粳米（人参）

### 腑证
- **治则**：泻下燥实
- **主方**：调胃承气汤、小承气汤、大承气汤
- **药物**：大黄、芒硝、枳实、厚朴等

## 适应证
- 高热不恶寒反恶热
- 大汗大渴
- 脉洪大
- 急性感染性疾病属气分热盛
- 糖尿病属肺胃热盛

## 禁忌证
- 表证未解者（白虎汤）
- 脾胃虚寒（白虎汤）
- 阴虚津亏（承气汤）
- 孕妇（承气汤）
- 脉沉微细（里虚）

## 变证及治法
| 变证 | 主方 |
|------|------|
| 热盛伤津（烦渴） | 白虎加人参汤 |
| 热结在里（表里俱热） | 白虎汤 |
| 燥屎内结 | 三承气汤 |
| 湿热发黄 | 茵陈蒿汤 |

## 预后
- 经证清热可解
- 腑证下之即愈
- 失治误治可致热厥、神昏
