# 少阳不和

## 基本信息
- 证型：少阳不和证
- 来源：《伤寒论》少阳病篇
- 所属体系：伤寒学派 · 六经辨证 · 少阳病
- 风险等级：低

## 证候表现
### 主症
- 往来寒热
- 胸胁苦满
- 嘿嘿不欲饮食
- 心烦喜呕

### 兼症
- 口苦
- 咽干
- 目眩
- 脉弦
- 舌淡红或淡白，苔薄白或薄黄

### 典型条文
《伤寒论》第263条："少阳之为病，口苦、咽干、目眩也。"

第96条："伤寒五六日，中风，往来寒热，胸胁苦满、嘿嘿不欲饮食、心烦喜呕……小柴胡汤主之。"

## 病机分析
- **病因**：邪犯少阳
- **病位**：半表半里（少阳经腑）
- **核心病机**：枢机不利，胆火内郁，正邪分争
- **特点**：寒热往来、枢机不利

## 辨证要点
| 部位 | 症状 |
|------|------|
| 口 | 口苦（胆火上炎） |
| 咽 | 咽干（津液被伤） |
| 目 | 目眩（清窍被扰） |
| 胸胁 | 苦满（气机不畅） |
| 脾胃 | 不欲食、喜呕（枢机不利） |
| 脉 | 弦（肝胆气郁） |

## 治法方药
- **治则**：和解少阳
- **主方**：小柴胡汤
- **药物**：柴胡、黄芩、人参、半夏、生姜、大枣、甘草
- **服法**：去滓再煎，分温三服

## 适应证
- 往来寒热、胸胁苦满、口苦咽干
- 外感病传少阳
- 肝胆疾病（胁痛、口苦）
- 消化系统疾病（肝胃不和）
- 妇人热入血室
- 情志病（肝郁）

## 禁忌证
- 纯太阳表证（须先解表）
- 纯阳明里实（须清下）
- 三阴虚寒证
- 阴虚火旺（潮热盗汗）
- 脉浮紧表实无少阳证

## 关键辨证原则
"伤寒中风，有柴胡证，但见一证便是，不必悉具。"（第101条）

## 变证及治法
| 变证 | 主方 |
|------|------|
| 少阳兼阳明里实 | 大柴胡汤 |
| 误下后柴胡证仍在 | 小柴胡汤 |
| 三阳合病 | 小柴胡汤 |
| 少阳阳明合病下利 | 黄芩汤 |

## 预后
- 少阳为枢，易传他经
- 和解得当可愈
- 失治误治可致坏病
