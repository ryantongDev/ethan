# 太阳表虚

## 基本信息
- 证型：太阳表虚证
- 来源：《伤寒论》太阳病篇
- 所属体系：伤寒学派 · 六经辨证 · 太阳病
- 风险等级：低

## 证候表现
### 主症
- 发热、恶风（或恶寒）
- 汗出
- 脉浮缓

### 兼症
- 头痛
- 项强
- 鼻鸣
- 干呕
- 舌淡红，苔薄白

### 典型条文
《伤寒论》第2条："太阳病，发热、汗出、恶风、脉缓者，名为中风。"

## 病机分析
- **病因**：风邪袭表
- **病位**：太阳经、卫分
- **核心病机**：卫阳不固，营阴外泄（卫强营弱）
- **转化**：可传少阳、阳明或太阴

## 辨证要点
| 要点 | 太阳表虚（中风） | 太阳表实（伤寒） |
|------|------------------|------------------|
| 发热 | 有（翕翕发热） | 有（或未发热） |
| 恶寒 | 恶风为主 | 恶寒为主 |
| 汗出 | 有（汗自出） | 无（身疼痛） |
| 脉象 | 浮缓 | 浮紧 |
| 头痛 | 有 | 有（身疼腰痛） |
| 喘 | 无或有（喘家） | 有（无汗而喘） |

## 治法方药
- **治则**：解肌祛风，调和营卫
- **主方**：桂枝汤
- **药物**：桂枝、芍药、生姜、大枣、甘草
- **服法**：啜热粥、温覆取微汗

## 适应证
- 发热恶风、汗出、脉浮缓
- 头痛项强
- 外感初起属表虚
- 病后、产后体虚外感
- 荨麻疹属风寒表虚

## 禁忌证
- 无汗、脉浮紧（麻黄汤证）
- 阳明里热（不恶寒反恶热）
- 阴虚津亏
- 湿热体质

## 变证及治法
| 变证 | 主方 |
|------|------|
| 项背强急 | 桂枝加葛根汤 |
| 喘家外感 | 桂枝加厚朴杏子汤 |
| 发汗漏不止 | 桂枝加附子汤 |
| 误下后气上冲 | 桂枝汤 |
| 误下后脉促胸满 | 桂枝去芍药汤 |

## 预后
- 预后良好
- 正气充足者可自愈
- 失治误治可传变他经
