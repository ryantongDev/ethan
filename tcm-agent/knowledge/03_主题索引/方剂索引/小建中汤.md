# 小建中汤

## 基本信息
- 方名：小建中汤
- 来源：《伤寒论》辨太阳病脉证并治中
- 所属体系：伤寒学派 · 太阴病 · 中焦虚寒（建中缓急）
- 风险等级：低

## 原文依据
- 来源：《伤寒论》第100条、第102条
- 原文关键句："伤寒，阳脉涩，阴脉弦，法当腹中急痛，先与小建中汤；不瘥者，小柴胡汤主之。""伤寒二三日，心中悸而烦者，小建中汤主之。"

## 方证要点
- 主症：腹中急痛（拘急疼痛、喜温喜按）、心中悸而烦
- 兼症：虚劳里急、气短乏力、面色无华、舌淡
- 舌象：舌淡苔薄白
- 脉象：虚弱或弦弱
- 病机：中焦虚寒，营卫不足，筋脉失养（虚劳腹痛）

## 组成逻辑
| 药物 | 作用 | 风险等级 |
|------|------|----------|
| 芍药 | 缓急止痛，养血敛阴 | 低 |
| 桂枝 | 温阳散寒，调和营卫 | 低 |
| 生姜 | 温中散寒，和胃止呕 | 低 |
| 大枣 | 补益脾胃，益气养血 | 低 |
| 甘草 | 益气和中，缓急止痛 | 低 |
| 胶饴 | 温中补虚，缓急止痛（重用） | 低（甘温滋腻） |

## 适合倾向
- 中焦虚寒之腹痛（拘急喜按）
- 虚劳病（气血两虚）
- 心悸心烦属心脾两虚
- 慢性胃炎、十二指肠溃疡属虚寒
- 痛经（冲任虚寒）
- 老年人气血不足便秘

## 不适合倾向
- 实热证腹痛（拒按、口苦、舌红）
- 湿热中阻（苔黄腻）
- 食积腹痛（嗳腐吞酸）
- 糖尿病患者（饴糖含糖量高）
- 阴虚火旺舌红少苔

## 加减方向
- 腹痛重 → 重用芍药
- 兼寒盛 → 加黄芪（黄芪建中汤）
- 气虚重 → 加黄芪、党参
- 寒凝腹痛 → 加吴茱萸、乌药
- 血虚 → 加当归

## 剂量与服法参考
- 剂量：桂枝三两，芍药六两，生姜三两，甘草二两，大枣十二枚，胶饴一升
- 煮法：以水七升，煮取三升，去滓，内饴，更上微火消解
- 服法：温服一升，日三服
- 注意：饴糖重用（甘温补虚）为君药

## 药物风险提示
- 胶饴：甘温滋腻，湿盛脘腹胀满者慎用
- 糖尿病患者：需换药或减量饴糖
- 芍药：虚寒腹痛重用时注意配伍
- 整体偏甘温，外感实热证禁用

## 适配评分规则
- 虚寒腹痛拘急：+5分
- 心中悸而烦：+3分
- 阳脉涩阴脉弦：+2分
- 面色无华气短：+2分
- 实热腹痛：-5分（禁忌）
- 舌红苔黄腻：-3分（湿热禁忌）
- 总分≥7分：建议使用；总分≤1分：禁忌
