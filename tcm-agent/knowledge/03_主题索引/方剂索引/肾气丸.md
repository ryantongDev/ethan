# 肾气丸

## 基本信息
- 方名：肾气丸（金匮肾气丸、桂附地黄丸）
- 来源：《金匮要略》血痹虚劳病脉证并治
- 所属体系：金匮学派 · 虚劳病 · 肾阳虚（补肾助阳）
- 风险等级：中

## 原文依据
- 来源：《金匮要略》
- 原文关键句："虚劳腰痛，少腹拘急，小便不利者，八味肾气丸主之。"

## 方证要点
- 主症：腰痛、少腹拘急、小便不利（尿频或不利）
- 兼症：舌淡胖、苔白、脉沉弱
- 舌象：舌淡胖，苔白
- 脉象：沉弱
- 病机：肾阳虚衰，气化无权

## 组成逻辑
| 药物 | 作用 | 风险等级 |
|------|------|----------|
| 熟地黄 | 滋阴补肾，填精益髓 | 低 |
| 山茱萸 | 补益肝肾，涩精缩尿 | 低 |
| 山药 | 补益脾胃，补肾涩精 | 低 |
| 泽泻 | 利水渗湿，泄热 | 低 |
| 茯苓 | 健脾渗湿，宁心安神 | 低 |
| 牡丹皮 | 清热凉血，活血化瘀 | 低 |
| 桂枝 | 温通肾阳，化气行水 | 中（温通） |
| 附子 | 温肾助阳，回阳救逆 | 高（有毒） |

## 适合倾向
- 肾阳虚（腰痛+小便不利）
- 前列腺增生属肾阳不足
- 尿频、尿急（肾气不固）
- 阳瘘（肾阳虚衰）
- 女子宫寒不孕
- 老年人肾虚腰痛

## 不适合倾向
- 阴虚火旺（舌红少苔、脉细数）
- 湿热下注（小便短赤、涩痛）
- 实热证
- 脾胃湿盛便溏（滋阴药碍湿）
- 孕妇（附子有毒性）

## 加减方向
- 腰痛甚 → 加杜仲、续断
- 尿频 → 加重山茱萸、益智仁
- 阳瘘 → 加淫羊藿、巴戟天
- 水肿 → 加车前子、牛膝
- 糖尿病 → 注意熟地含糖量

## 剂量与服法参考
- 剂量：干地黄八两，山茱萸、山药各四两，泽泻、茯苓、牡丹皮各三两，桂枝、附子各一两
- 制法：研末，炼蜜和丸如梧子大
- 服法：酒服十五丸，不知，加至二十五丸
- 注意：附子须炮制，久煎

## 药物风险提示
- 附子：有毒，须炮制，久煎
- 桂枝：温燥，阴虚火旺者慎用
- 整体温热为主，阴虚火旺者绝对禁用

## 适配评分规则
- 肾阳虚证（腰痛+小便不利+舌淡胖）：+5分
- 脉沉弱：+2分
- 少腹拘急：+2分
- 尿频或不利：+2分
- 阴虚火旺（舌红少苔）：-5分（绝对禁忌）
- 湿热下注：-3分
- 总分≥7分：建议使用；总分≤0分：禁忌
