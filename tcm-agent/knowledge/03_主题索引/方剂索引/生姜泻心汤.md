# 生姜泻心汤

## 基本信息
- 方名：生姜泻心汤
- 来源：《伤寒论》辨太阳病脉证并治下
- 所属体系：伤寒学派 · 太阳病误下致痞（水气痞）
- 风险等级：低

## 原文依据
- 来源：《伤寒论》第157条
- 原文关键句："伤寒汗出解之后，胃中不和，心下痞硬，干噫食臭，胁下有水气，腹中雷鸣下利者，生姜泻心汤主之。"

## 方证要点
- 主症：心下痞硬、干噫食臭（嗳气有酸腐味）、腹中雷鸣下利
- 兼症：胁下有水气感、肠鸣辘辘
- 舌象：舌淡胖齿痕，苔白腻或白滑
- 脉象：濡缓或弦
- 病机：脾胃虚弱，水气内停，寒热错杂（水气痞）

## 组成逻辑
| 药物 | 作用 | 风险等级 |
|------|------|----------|
| 生姜 | 温胃散水，和胃止呕（重用） | 低 |
| 半夏 | 降逆和胃，燥湿消痞 | 低 |
| 黄芩 | 清热降逆，燥湿止利 | 低 |
| 黄连 | 清热燥湿，厚肠止利 | 低 |
| 人参 | 益气健脾，补虚扶正 | 低 |
| 甘草 | 益气和中，调和诸药 | 低 |
| 大枣 | 补益脾胃，益气养血 | 低 |
| 干姜 | 温中散寒（用量减） | 低 |

## 适合倾向
- 水气内停之痞证（痞硬+肠鸣下利）
- 胃下垂、胃潴留属水饮停聚
- 慢性结肠炎（寒热错杂兼水气）
- 消化不良嗳气酸腐
- 妊娠恶阻属胃虚有水

## 不适合倾向
- 无水气之单纯痞证（半夏泻心汤）
- 脾胃阳虚无热象（理中汤）
- 纯湿热腹泻（水样便、黄稠）
- 阴虚火旺舌红少苔

## 加减方向
- 水气重 → 加茯苓、泽泻
- 腹泻重 → 加重黄连用量
- 嗳气重 → 加旋覆花、代赭石
- 兼食积 → 加神曲、麦芽

## 剂量与服法参考
- 剂量：生姜四两（为主），半夏半升，黄芩、人参、甘草各三两，黄连一两，干姜一两，大枣十二枚
- 煮法：以水一斗，煮取六升，去滓再煎取三升
- 服法：温服一升，日三服
- 注意：重用生姜散水气为本方特点

## 药物风险提示
- 生姜：阴虚火旺、热证者慎用
- 黄连、黄芩：苦寒易伤脾胃阳气
- 整体偏温燥，津亏者需配伍健脾养阴药

## 适配评分规则
- 心下痞硬+干噫食臭+腹鸣下利：+5分
- 舌淡胖齿痕、苔白腻：+3分
- 脉濡缓：+2分
- 胁下有水气感：+2分
- 无水气证据（单纯痞满）：-3分（宜半夏泻心汤）
- 舌红少苔、津亏：-2分
- 总分≥7分：建议使用；总分≤1分：需调整
