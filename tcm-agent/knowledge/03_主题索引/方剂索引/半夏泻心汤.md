# 半夏泻心汤

## 基本信息
- 方名：半夏泻心汤
- 来源：《伤寒论》辨太阳病脉证并治下
- 所属体系：伤寒学派 · 太阳病误下致痞
- 风险等级：低

## 原文依据
- 来源：《伤寒论》第149条
- 原文关键句："伤寒五六日，呕而发热者，柴胡汤证具，而以他药下之，柴胡证仍在者，复与柴胡汤……若心下满而硬痛者，此为结胸也，大陷胸汤主之；但满而不痛者，此为痞，柴胡不中与之，宜半夏泻心汤。"

## 方证要点
- 主症：心下痞满（但满不痛）、呕逆、肠鸣下利
- 兼症：食欲不振、苔薄黄腻
- 舌象：舌淡红，苔黄腻或白腻
- 脉象：濡缓或弦
- 病机：寒热错杂于中焦，脾胃升降失常（痞证）

## 组成逻辑
| 药物 | 作用 | 风险等级 |
|------|------|----------|
| 半夏 | 降逆和胃，燥湿化痰 | 低 |
| 黄芩 | 清热燥湿，降逆止呕 | 低 |
| 黄连 | 清热燥湿，厚肠止利 | 低 |
| 干姜 | 温中散寒，和胃止呕 | 低 |
| 人参 | 益气健脾，补虚扶正 | 低 |
| 甘草 | 益气和中，调和诸药 | 低 |
| 大枣 | 补益脾胃，益气养血 | 低 |

## 适合倾向
- 寒热错杂之痞证（心下痞满不痛）
- 急性胃肠炎（呕逆、肠鸣、腹泻）
- 慢性胃炎属寒热错杂
- 消化不良属湿热中阻
- 口腔溃疡属湿热内蕴
- 失眠（胃不和则卧不安）

## 不适合倾向
- 脾胃虚寒无热象
- 纯湿热无寒象（应用黄连汤等）
- 阴虚津亏舌红少苔
- 食积不化（保和丸证）
- 单纯表证

## 加减方向
- 呕逆重 → 重用半夏、生姜
- 腹泻重 → 重用黄连、干姜
- 湿重 → 加苍术、茯苓
- 兼食积 → 加神曲、麦芽

## 剂量与服法参考
- 剂量：半夏半升，黄芩、干姜、人参、甘草各三两，黄连一两，大枣十二枚
- 煮法：以水一斗，煮取六升，去滓再煎取三升
- 服法：温服一升，日三服

## 药物风险提示
- 黄连、黄芩：苦寒易伤脾胃阳气，脾胃虚寒者慎用
- 干姜：温燥，阴虚火旺者慎用
- 整体偏苦寒燥湿，津亏者需配伍健脾养阴药

## 适配评分规则
- 心下痞满不痛：+5分
- 呕逆+肠鸣下利：+3分
- 苔黄腻或白腻：+2分
- 脉濡缓：+2分
- 脾胃虚寒无热象：-3分（宜理中汤）
- 纯湿热无寒象：-2分
- 总分≥6分：建议使用；总分≤1分：需辨证调整
