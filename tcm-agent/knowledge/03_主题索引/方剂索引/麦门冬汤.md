# 麦门冬汤

## 基本信息
- 方名：麦门冬汤
- 来源：《金匮要略》肺痿肺痈咳嗽上气病脉证治
- 所属体系：金匮学派 · 肺病 · 肺阴不足（虚火咳逆）
- 风险等级：低

## 原文依据
- 来源：《金匮要略》
- 原文关键句："火逆上气，咽喉不利，止逆下气者，麦门冬汤主之。"

## 方证要点
- 主症：咳嗽气喘、咽喉不利（干痒、异物感）、咳痰不爽
- 兼症：舌红少苔、脉虚数
- 舌象：舌红少苔
- 脉象：虚数
- 病机：肺阴不足，虚火上炎，肺失肃降

## 组成逻辑
| 药物 | 作用 | 风险等级 |
|------|------|----------|
| 麦门冬 | 滋阴润燥，清热止咳（重用） | 低 |
| 半夏 | 降逆化痰，止咳平喘 | 低 |
| 人参 | 益气补虚，扶正祛邪 | 低 |
| 甘草 | 益气和中，调和诸药 | 低 |
| 粳米 | 补益脾胃，益气生津 | 低 |
| 大枣 | 补益脾胃，益气养血 | 低 |

## 适合倾向
- 肺阴不足之咳嗽（干咳少痰）
- 慢性支气管炎属阴虚咳喘
- 咽喉干燥、声音嘶哑
- 肺痿（涎唾多、虚火咳逆）
- 肺癌放化疗后干咳（需辨证）
- 反流性食管炎咽喉异物感（需辨证）

## 不适合倾向
- 寒痰咳嗽（痰白清稀）
- 湿痰咳嗽（痰多色白）
- 脾胃虚寒便溏
- 外感风寒咳嗽
- 肺阴亏损已极（重症需另方）

## 加减方向
- 阴虚重 → 重用麦门冬
- 咳痰不爽 → 可加贝母、桔梗
- 咽喉干燥 → 加玄参、生地
- 伴有气喘 → 加紫菀、款冬花
- 合并感染 → 需另加清热药

## 剂量与服法参考
- 剂量：麦门冬七升，半夏一升，人参、甘草、粳米各三两，大枣十二枚
- 煮法：以水一斗二升，煮取六升
- 服法：温服一升，日三夜一服
- 注意：重用麦门冬滋阴清热

## 药物风险提示
- 半夏：性温燥，阴虚干咳者慎用（方中麦门冬可佐制）
- 整体偏凉，脾胃虚寒者慎用
- 痰热咳嗽不宜

## 适配评分规则
- 肺阴不足咳嗽（干咳少痰+舌红少苔）：+5分
- 咽喉不利干痒：+3分
- 虚火上炎脉虚数：+2分
- 痰白清稀寒痰：-4分（禁忌）
- 脾胃虚寒便溏：-2分
- 外感风寒：-3分（应先解表）
- 总分≥7分：建议使用；总分≤0分：禁忌
