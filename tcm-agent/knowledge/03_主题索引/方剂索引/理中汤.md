# 理中汤

## 基本信息
- 方名：理中汤（理中丸）
- 来源：《伤寒论》辨霍乱病脉证并治
- 所属体系：伤寒学派 · 太阴病 · 中焦虚寒
- 风险等级：低

## 原文依据
- 来源：《伤寒论》第386条
- 原文关键句："霍乱，头痛、发热、身疼痛、热多欲饮水者，五苓散主之；寒多不用水者，理中丸主之。"

## 方证要点
- 主症：呕吐、下利、腹痛喜温喜按、口不渴
- 兼症：腹满食少、畏寒喜暖、舌淡苔白
- 舌象：舌淡苔白
- 脉象：虚弱或沉迟
- 病机：中焦虚寒，脾胃升降失常

## 组成逻辑
| 药物 | 作用 | 风险等级 |
|------|------|----------|
| 人参 | 益气健脾，补虚扶正 | 低 |
| 干姜 | 温中散寒，和胃止呕 | 低 |
| 白术 | 健脾燥湿，益气止泻 | 低 |
| 甘草 | 益气和中，调和诸药 | 低 |

## 适合倾向
- 太阴病中焦虚寒（吐利不渴、腹痛喜按）
- 急性胃肠炎（寒湿型）
- 慢性胃炎属脾胃虚寒
- 虚寒性腹痛（得温则减）
- 阳虚体质（畏寒喜暖）
- 病后脾胃虚弱

## 不适合倾向
- 实热证（口苦、舌红、苔黄）
- 阴虚舌红少苔
- 湿热腹泻（里急后重、肛门灼热）
- 食积腹胀（嗳腐吞酸）
- 燥屎内结

## 加减方向
- 脐上筑动（肾气动）→ 去术加桂
- 吐多 → 去术加生姜
- 下多 → 还用术
- 心悸 → 加茯苓
- 渴欲得水 → 重用白术
- 腹痛 → 重用人参
- 寒盛 → 重用干姜
- 腹满 → 去术加附子

## 剂量与服法参考
- 剂量：人参、干姜、甘草、白术各三两
- 煮法：以四物切，用水八升，煮取三升，去滓
- 服法：温服一升，日三服
- 丸法：蜜和为丸如鸡子黄许，研碎温服
- 注意：服汤后如食顷，饮热粥一升许

## 药物风险提示
- 干姜：温燥，阴虚火旺者慎用
- 白术：性温燥，津亏便秘者慎用
- 整体偏温，实热证禁用

## 适配评分规则
- 太阴虚寒证（吐利不渴+腹痛喜温）：+5分
- 口不渴：+2分
- 畏寒喜暖：+2分
- 舌淡苔白脉虚弱：+2分
- 实热证或阴虚：-5分（禁忌）
- 湿热腹泻：-3分
- 总分≥7分：建议使用；总分≤1分：需辨证
