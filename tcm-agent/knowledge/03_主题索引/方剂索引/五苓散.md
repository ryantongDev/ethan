# 五苓散

## 基本信息
- 方名：五苓散
- 来源：《伤寒论》辨太阳病脉证并治中
- 所属体系：伤寒学派 · 太阳病 · 膀胱气化不利（蓄水证）
- 风险等级：低

## 原文依据
- 来源：《伤寒论》第71条、第72条、第73条
- 原文关键句："太阳病，发汗后，大汗出，胃中干，烦躁不得眠，欲得饮水者，少少与饮之，令胃气和则愈；若脉浮、小便不利、微热消渴者，五苓散主之。"

## 方证要点
- 主症：小便不利、渴欲饮水、发热、脉浮
- 兼症：烦渴多饮、水入即吐（渴消水逆）、水湿内停
- 舌象：舌淡胖，苔白腻或水滑
- 脉象：浮数或濡缓
- 病机：膀胱气化不利，水湿内停，兼表邪未解

## 组成逻辑
| 药物 | 作用 | 风险等级 |
|------|------|----------|
| 猪苓 | 利水渗湿，清热利尿 | 低 |
| 泽泻 | 利水渗湿，泄热 | 低 |
| 茯苓 | 健脾渗湿，宁心安神 | 低 |
| 白术 | 健脾燥湿，益气利水 | 低 |
| 桂枝 | 化气解表，通阳利水 | 低 |

## 适合倾向
- 太阳蓄水证（表邪未解+水蓄膀胱）
- 急性肾炎水肿初起
- 泌尿系统感染属湿热下注
- 水湿内停之泄泻（水样便）
- 肥胖症属水湿内停
- 痰饮病（水气上凌）

## 不适合倾向
- 阴虚津亏（小便不利非水蓄）
- 脾胃虚寒大便溏泄
- 湿热壅盛无气化障碍
- 肾阳虚衰水肿
- 孕妇（水湿重者需辨证）

## 加减方向
- 兼表证 → 加重桂枝或加麻黄
- 水肿重 → 加车前子、冬瓜皮
- 湿热带下 → 去桂枝加黄柏
- 寒湿泄泻 → 加干姜、肉桂

## 剂量与服法参考
- 剂量：猪苓、白术、茯苓各十八铢，泽泻一两六铢，桂枝半两
- 制法：为散，更于臼中杵之
- 服法：白饮和服方寸匕，日三服；多饮暖水，汗出愈
- 注意：散剂便于服用，利水较汤剂缓

## 药物风险提示
- 泽泻：性寒，肾虚滑精者慎用
- 猪苓、茯苓：渗利伤阴，阴虚津亏者慎用
- 整体偏利，脾胃虚寒者慎用或配伍健脾药

## 适配评分规则
- 太阳蓄水证（小便不利+渴欲饮水+脉浮）：+5分
- 水湿内停水肿：+3分
- 水入即吐（逆）：+2分
- 舌淡胖苔白腻：+2分
- 阴虚津亏舌红少苔：-4分（禁忌）
- 肾阳虚衰水肿：-2分（应济生肾气丸）
- 总分≥7分：建议使用；总分≤0分：禁忌
