# 大柴胡汤

## 基本信息
- 方名：大柴胡汤
- 来源：《伤寒论》辨太阳病脉证并治下
- 所属体系：伤寒学派 · 太阳病转少阳兼里实
- 风险等级：中

## 原文依据
- 来源：《伤寒论》第103条
- 原文关键句："太阳病，过经十余日，反二、三下之。后四、五日，柴胡证仍在者，先与小柴胡。呕不止、心下急、郁郁微烦者，为未解也，与大柴胡汤下之则愈。"

## 方证要点
- 主症：呕不止、心下急（脘腹胀满）、郁郁微烦（热郁）
- 兼症：往来寒热、胸胁苦满仍在、便秘或下利
- 舌象：舌红，苔黄
- 脉象：弦数
- 病机：少阳郁热兼入阳明，胃家实已成

## 组成逻辑
| 药物 | 作用 | 风险等级 |
|------|------|----------|
| 柴胡 | 和解少阳，疏肝清热 | 低 |
| 黄芩 | 清泄少阳、阳明郁热 | 低 |
| 芍药 | 缓急止痛，养血柔肝 | 低 |
| 半夏 | 和胃降逆止呕 | 低 |
| 生姜 | 和胃止呕，散寒解表 | 低 |
| 枳实 | 行气消痞，破结除满 | 中（破气） |
| 大枣 | 益气养血，护胃气 | 低 |
| 大黄 | 泻热通便，荡涤肠胃 | 中（清热攻下） |

## 适合倾向
- 少阳兼阳明里实（大柴胡证）
- 急性胆囊炎、胆结石急性发作
- 急性胰腺炎（肝胆湿热）
- 肝郁化火兼腑气不通
- 高热不退属少阳阳明合病

## 不适合倾向
- 纯少阳证无里实（宜小柴胡汤）
- 纯阳明经证（无胸胁苦满）
- 三阴虚寒证
- 孕妇及体质虚弱者（慎用或减量）
- 脾胃虚寒、大便溏泄者

## 加减方向
- 胁下痞硬 → 去大枣加牡蛎
- 兼黄疸 → 加茵陈、栀子
- 结石 → 加金钱草、海金沙
- 疼痛剧烈 → 加延胡索、川楝子

## 剂量与服法参考
- 剂量：柴胡半斤，黄芩、芍药、半夏各三两，生姜五两，枳实四枚，大枣十二枚（大黄二两据证另加）
- 煮法：以水一斗二升，煮取六升，去滓再煎
- 服法：温服一升，日三服
- 注意：原方大黄可酌情另加，示人临证变通

## 药物风险提示
- 大黄：泻下力强，脾胃虚寒者慎用；孕妇忌用
- 枳实：破气消痞，体虚者慎用
- 柴胡：阴虚火旺者慎用大量
- 整体以清热通下为主，不可久用

## 适配评分规则
- 少阳兼里实（呕不止+心下急+郁郁微烦）：+5分
- 往来寒热仍存：+3分
- 大便秘结：+3分
- 脉弦数：+2分
- 仅有少阳证无里实：-3分（宜小柴胡）
- 脾胃虚寒便溏：-4分（禁忌）
- 脉微弱体虚：-3分
- 总分≥7分：建议使用；总分≤0分：禁忌或调整
