# 甘草泻心汤

## 基本信息
- 方名：甘草泻心汤
- 来源：《伤寒论》辨太阳病脉证并治下
- 所属体系：伤寒学派 · 太阳病误下致痞（虚痞）
- 风险等级：低

## 原文依据
- 来源：《伤寒论》第158条
- 原文关键句："伤寒中风，医反下之，其人下利日数十行，谷不化，腹中雷鸣，心下痞硬而满，干呕心烦不得安。医见心下痞，谓病不尽，复下之，其痞益甚。此非热结，但以胃中虚，客气上逆，故使硬也，甘草泻心汤主之。"

## 方证要点
- 主症：心下痞硬而满、下利日数十行、谷不化、腹中雷鸣、干呕心烦
- 兼症：反复误下后胃气大虚
- 舌象：舌淡苔少或薄白
- 脉象：虚弱
- 病机：脾胃大虚，寒热错杂，客气上逆（虚痞）

## 组成逻辑
| 药物 | 作用 | 风险等级 |
|------|------|----------|
| 甘草 | 补益脾胃，缓急和中（重用） | 低 |
| 半夏 | 降逆和胃，燥湿化痰 | 低 |
| 黄芩 | 清热降逆，燥湿止利 | 低 |
| 黄连 | 清热燥湿，厚肠止利 | 低 |
| 干姜 | 温中散寒，和胃止呕 | 低 |
| 人参 | 益气健脾，补虚扶正 | 低 |
| 大枣 | 补益脾胃，益气养血 | 低 |

## 适合倾向
- 脾胃虚极之痞证（下利、谷不化）
- 溃疡性结肠炎（反复腹泻）
- 白塞病（口腔+眼部+生殖器溃疡）
- 干燥综合征（需辨证）
- 失眠心烦属胃虚热扰
- 病毒性心肌炎恢复期（需辨证）

## 不适合倾向
- 实证痞满（无虚象）
- 阴虚火旺舌红少苔
- 湿热腹泻（黄稠臭秽）
- 食积腹胀（嗳腐吞酸）
- 热盛烦躁无虚象

## 加减方向
- 腹泻重 → 加山药、莲子
- 谷不化 → 加神曲、麦芽
- 心烦重 → 加栀子、淡豆豉
- 溃疡 → 合甘草泻心汤重用甘草

## 剂量与服法参考
- 剂量：甘草四两（为主），半夏半升，黄芩、干姜、人参各三两，黄连一两，大枣十二枚
- 煮法：以水一斗，煮取六升，去滓再煎取三升
- 服法：温服一升，日三服
- 注意：重用甘草补虚缓中为本方特点

## 药物风险提示
- 甘草：大量久服可引起水钠潴留（高血压患者慎用大量久服）
- 黄连、黄芩：苦寒易伤脾胃阳气
- 整体偏补虚，湿热实证慎用

## 适配评分规则
- 心下痞硬+下利日数十行+谷不化：+5分
- 干呕心烦不得安：+3分
- 舌淡苔少、脉虚弱：+3分
- 反复误下病史：+2分
- 实证痞满无虚象：-4分（禁忌）
- 舌红苔黄腻（湿热）：-2分
- 总分≥8分：建议使用；总分≤1分：需辨证
