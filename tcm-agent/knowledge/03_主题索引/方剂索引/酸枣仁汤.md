# 酸枣仁汤

## 基本信息
- 方名：酸枣仁汤
- 来源：《金匮要略》血痹虚劳病脉证并治
- 所属体系：金匮学派 · 虚劳病 · 肝血不足（虚烦不眠）
- 风险等级：低

## 原文依据
- 来源：《金匮要略》
- 原文关键句："虚劳虚烦不得眠，酸枣仁汤主之。"

## 方证要点
- 主症：虚烦不眠（难以入睡或多梦易醒）、心悸不安
- 兼症：头晕目眩、咽干口燥、舌红少苔、脉弦细
- 舌象：舌红少苔
- 脉象：弦细
- 病机：肝血不足，虚热内生，心神失养

## 组成逻辑
| 药物 | 作用 | 风险等级 |
|------|------|----------|
| 酸枣仁 | 养肝血，安心神（重用） | 低 |
| 知母 | 清热除烦，滋阴润燥 | 低 |
| 川芎 | 行气活血，调肝止痛 | 中（活血行气） |
| 茯苓 | 健脾渗湿，宁心安神 | 低 |
| 甘草 | 益气和中，调和诸药 | 低 |

## 适合倾向
- 虚烦不眠（肝血不足型）
- 神经衰弱、焦虑症属虚烦
- 产后失眠（血虚）
- 心悸怔忡属血虚有热
- 围绝经期失眠（肝血不足）
- 慢性肝炎失眠（需辨证）

## 不适合倾向
- 痰热内扰之失眠（舌红苔黄腻）
- 食积内停之失眠（嗳腐吞酸）
- 瘀血阻滞之失眠（舌暗有瘀斑）
- 实热证（脉数有力）
- 脾胃虚寒便溏（知母性寒）

## 加减方向
- 虚烦重 → 重用知母，加栀子
- 盗汗 → 加五味子、牡蛎
- 兼肝郁 → 加柴胡、香附
- 血虚甚 → 加当归、龙眼肉
- 心悸重 → 加远志、合欢皮

## 剂量与服法参考
- 剂量：酸枣仁二升，知母、川芎、茯苓、甘草各二两
- 煮法：以水八升，煮酸枣仁取六升，内诸药煮取三升
- 服法：分温三服
- 注意：重用酸枣仁养心安神

## 药物风险提示
- 知母：性寒质润，脾胃虚寒便溏者慎用
- 川芎：活血行气，阴虚火旺者慎用
- 整体偏寒，脾胃虚寒者慎用

## 适配评分规则
- 虚烦不眠+舌红少苔：+5分
- 心悸不安：+3分
- 脉弦细：+2分
- 头晕咽干：+2分
- 痰热内扰（苔黄腻）：-4分（禁忌）
- 实热脉数：-3分
- 总分≥7分：建议使用；总分≤1分：需辨证
