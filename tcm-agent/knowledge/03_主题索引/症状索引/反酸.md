# 反酸

## 可能辨证方向
1. **肝火犯胃** — 反酸烧心，口苦咽干，烦躁易怒，舌红苔黄，脉弦数
2. **脾胃湿热** — 反酸粘腻，嗳气口臭，胸骨后灼热，舌红苔黄腻，脉滑数
3. **胃气上逆** — 反酸频作，餐后加重，伴胃胀，舌淡苔白，脉沉弱
4. **痰气互结** — 反酸伴咽部异物感，胸闷，舌淡苔白腻，脉弦滑

## 需要追问
- 反酸发生在何时？（餐后/夜间/空腹）
- 是否有烧心、胸骨后灼热感？
- 伴随口苦、口臭、胸闷？
- 舌象（舌色、苔色苔质）、脉象（若知）
- 近期饮食偏好（辛辣/甜腻/生冷）
- 情绪状况

## 经典依据
- 《临证指南医案》"泛吐酸水，乃肝气犯胃"
- 《素问·至真要大论》"诸呕吐酸，暴注下迫，皆属于热"

## 药食同源调理方向
- **海螵蛸**（制酸）：研粉3g，温水冲服（收敛制酸）
- **瓦楞子**（制酸止痛）：煅瓦楞子研粉3-5g
- **吴茱萸**（温中降逆）：吴茱萸1-2g，研粉调醋敷涌泉（肝火犯胃）
- **猴头菇**（养胃）：猴头菇煮汤（胃阴不足适用）

**禁忌**：辛辣刺激、甜腻饮食、巧克力、咖啡；晚餐不宜过饱；避免餐后立即平卧

## 穴位按摩方向
- **中脘**：按揉3分钟，和胃降逆
- **内关**：点按2分钟，宽胸止呕
- **公孙**（第1跖骨基底前方）：按揉3分钟，健脾和胃
- **太冲**：点按2分钟，疏肝清火

**操作建议**：公孙和太冲可重点按压，早晚各一次；反酸发作时半卧位缓解
