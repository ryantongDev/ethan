# 乏力

## 可能辨证方向
1. **气虚** — 乏力以四肢为主，懒言少动，易自汗，舌淡苔白，脉虚弱
2. **湿困脾胃** — 乏力沉重，胸闷脘痞，舌淡苔白腻，脉濡缓
3. **气血两虚** — 乏力伴头晕眼花，心悸失眠，舌淡苔白，脉细弱
4. **肾精不足** — 乏力兼腰膝酸软，记忆力下降，舌淡苔少，脉沉细
5. **阳虚** — 乏力畏寒，四肢不温，舌淡胖苔白，脉沉迟

## 需要追问
- 乏力是全身还是局部？（四肢/腰膝/头部）
- 伴随自汗、盗汗、畏寒？
- 是否伴有头晕、心悸、失眠？
- 舌象（舌色、苔色苔质）、脉象（若知）
- 近期体重变化、饮食状况、睡眠质量
- 既往病史（糖尿病、甲状腺等）

## 经典依据
- 《素问·宣明五气》"久卧伤气"
- 《中医内科学》"气虚则懈怠"

## 药食同源调理方向
- **黄芪**（补气固表）：黄芪10g，大枣3枚，煮水代茶
- **山药**（健脾益气）：山药30g，煮粥或蒸食
- **党参**（补中益气）：党参10g，枸杞5g，煮水（气阴两虚）
- **龙眼肉**（补益心脾）：龙眼肉10g，蒸服（气血不足）

**禁忌**：湿困者忌甘腻甜食；气虚慎用苦寒药；阳虚忌生冷

## 穴位按摩方向
- **足三里**：按揉3分钟，健脾补气
- **气海**（脐下1.5寸）：按揉2分钟，补益元气
- **关元**（脐下3寸）：按揉2分钟，培元固本
- **三阴交**（内踝上3寸）：按揉2分钟，健脾养血

**操作建议**：艾灸足三里、关元（气虚/阳虚型）；每日1次，每次每穴2-3分钟
