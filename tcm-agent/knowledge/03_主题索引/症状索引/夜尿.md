# 夜尿

## 可能辨证方向
1. **肾阳虚衰** — 夜尿频多，清长量多，畏寒肢冷，腰膝酸软，舌淡苔白，脉沉弱
2. **膀胱湿热** — 夜尿频急，尿黄浑浊，尿道灼热，舌红苔黄腻，脉滑数
3. **肺气虚** — 夜尿清长，伴有乏力、咳喘，舌淡苔白，脉虚弱
4. **脾肾两虚** — 夜尿频多，伴有便溏、乏力，舌淡苔白，脉沉弱

## 需要追问
- 夜尿次数？每次尿量多少？
- 尿色是否清长或黄赤？
- 是否伴有尿道灼热、疼痛？
- 是否畏寒肢冷、腰膝酸软？
- 舌象（舌色、苔色苔质）、脉象（若知）
- 既往是否有前列腺疾病、尿路感染、糖尿病

## 相关方证
| 方剂 | 适应证 | 关键指征 |
|------|--------|----------|
| 缩泉丸 | 肾阳虚 | 夜尿频多，清长，脉沉弱 |
| 桑螵蛸散 | 肾气不固 | 夜尿频多，伴有遗尿 |
| 无比山药丸 | 脾肾两虚 | 夜尿频多，便溏乏力 |
| 八正散 | 膀胱湿热 | 夜尿急迫，尿黄，苔黄腻 |

## 经典依据
- 《素问·灵兰秘典论》"膀胱者，州都之官，津液藏焉，气化则能出矣"
- 《诸病源候论》"肾虚则小便数"

## 药食同源调理方向
- **益智仁**（温肾缩尿）：益智仁5g，乌药3g，煮水（肾阳虚）
- **山药**（健脾补肾）：山药30g，芡实15g，煮粥
- **覆盆子**（固精缩尿）：覆盆子10g，煮水代茶
- **南瓜子**（温肾利水）：生南瓜子10g，咀嚼（前列腺肥大方）

**禁忌**：膀胱湿热忌温补涩敛；睡前2小时限制饮水；忌咖啡因饮料

## 穴位按摩方向
- **关元**：按揉3分钟，补肾固尿
- **中极**（脐下4寸）：按揉3分钟，助膀胱气化
- **三阴交**：按揉2分钟，健脾补肾
- **涌泉**：搓3分钟，温肾助阳

**操作建议**：艾灸关元、中极（肾阳虚型）；每穴按揉2分钟，早晚各1次
