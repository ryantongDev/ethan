# 水肿

## 可能辨证方向
1. **脾虚水停** — 水肿以下肢为主，晨轻暮重，脘闷腹胀，舌淡苔白，脉虚弱
2. **肾阳虚水泛** — 水肿明显，腰以下为甚，畏寒肢冷，舌淡胖苔白，脉沉弱
3. **肺气不宣** — 眼睑浮肿为主，伴咳嗽、气喘，舌淡苔白，脉浮
4. **湿热蕴结** — 肿胀明显，皮肤绷急光亮，舌红苔黄腻，脉滑数
5. **气滞水停** — 肿胀随情绪变化，胁肋胀满，舌淡苔白，脉弦

## 需要追问
- 水肿从何处开始？（眼睑/下肢/全身）
- 晨起还是午后加重？
- 皮肤是否绷急光亮？
- 伴随畏寒、腰膝酸软、喘咳？
- 舌象（舌色、苔色苔质）、脉象（若知）
- 既往心脏病、肾病、肝病、甲状腺功能

**⚠️ 警告**：全身水肿急性加重、伴尿少喘憋，务必立即就医（心肾肝危象）

## 经典依据
- 《素问·至真要大论》"诸湿肿满，皆属于脾"
- 《金匮要略》"腰以上肿，当发汗乃愈；腰以下肿，当利小便"

## 药食同源调理方向
- **玉米须**（利水消肿）：玉米须30g，煎水代茶（轻症）
- **冬瓜皮**（利水消肿）：冬瓜皮30g，煮水（湿热水肿）
- **赤小豆**（健脾利水）：赤小豆30g，煮粥（脾虚水肿）
- **茯苓**（健脾利水）：茯苓30g，煮粥或打粉冲服

**禁忌**：肾阳虚忌生冷；湿热忌温补；严格限制盐的摄入（每日<3g）；胸腹水患者限水
