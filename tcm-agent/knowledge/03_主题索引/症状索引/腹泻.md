# 腹泻

## 可能辨证方向
1. **寒湿困脾** — 腹泻清稀如水，腹痛肠鸣，舌淡苔白腻，脉濡缓
2. **脾虚湿盛** — 大便溏薄，食后即泻，神疲乏力，舌淡苔白，脉虚弱
3. **肝脾不和** — 腹痛即泻，泻后痛减，情绪紧张诱发，脉弦
4. **肾阳虚衰** — 五更泄泻，黎明即泻，畏寒肢冷，舌淡苔白，脉沉细
5. **湿热下注** — 腹泻急迫，肛门灼热，大便臭秽，舌红苔黄腻，脉滑数

## 需要追问
- 大便性状：水样/稀溏/夹有不消化食物？
- 腹痛部位及性质？
- 是否有肛门灼热、里急后重？
- 与饮食关系？（不洁饮食后/受凉后/情绪相关）
- 舌象（舌色、苔色苔质）、脉象（若知）
- 既往体质及大便习惯

## 经典依据
- 《难经》"湿多成五泄"
- 《景岳全书》"泄泻之本，无不由于脾胃"

## 药食同源调理方向
- **炒薏苡仁**（健脾渗湿）：炒薏仁30g煮粥（日1次）
- **焦山楂**（消食止泻）：焦山楂15g，煎水服
- **石榴皮**（涩肠止泻）：石榴皮3-5g，煎水（急慢性腹泻）
- **炒白扁豆**（健脾化湿）：炒扁豆30g，煮粥

**禁忌**：生冷油腻；湿热泄泻禁补涩；脾虚泄泻控制粗纤维摄入

## 穴位按摩方向
- **天枢**（脐旁2寸）：按揉3分钟，调理肠腑
- **足三里**：按揉3分钟，健脾止泻
- **中脘**：按揉2分钟，和中止泻
- **上巨虚**（足三里下3寸）：按揉2分钟，大肠下合穴

**操作建议**：艾灸天枢、足三里（寒湿/脾虚型）；湿热型宜针刺忌灸；每日2-3次
