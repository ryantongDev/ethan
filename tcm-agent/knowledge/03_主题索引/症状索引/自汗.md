# 自汗

## 可能辨证方向
1. **肺气虚** — 自汗轻微，动则加重，易感冒，舌淡苔白，脉虚弱
2. **卫阳不固** — 汗出恶风，周身酸楚，容易感冒，舌淡苔白，脉浮缓
3. **营卫不和** — 汗出恶风，时寒时热，舌淡苔白，脉浮缓
4. **阳明热盛** — 汗出量大，面赤烘热，口渴喜冷，舌红苔黄，脉洪大
5. **阴虚火旺** — 夜间盗汗，或自汗少量，潮热盗汗，舌红少苔，脉细数

## 需要追问
- 出汗时间：白天自汗/夜间盗汗/两者都有？
- 汗量多少？是否湿透衣物？
- 是否伴有恶风、易感冒？
- 伴随潮热、盗汗、五心烦热？
- 舌象（舌色、苔色苔质）、脉象（若知）
- 既往体质（是否容易感冒、是否有慢性病）

## 经典依据
- 《素问·阴阳别论》"阳加于阴谓之汗"
- 《金匮要略》"自汗出者，此为荣气和，外不谐，以卫气不共荣气谐和故尔"

## 药食同源调理方向
- **黄芪**（固表止汗）：黄芪10g，白术6g，防风3g，煮水（玉屏风简化方）
- **浮小麦**（收敛止汗）：浮小麦30g，大枣5枚，煮水代茶
- **五味子**（敛肺止汗）：五味子5g，麦冬10g，煮水（气阴两虚）
- **山药**（补脾益肺）：山药30g，煮粥

**禁忌**：自汗切忌用麻黄（发汗峻剂）；阴虚火旺忌辛辣；卫阳不固忌生冷

## 穴位按摩方向
- **合谷**：按揉3分钟，调节汗液
- **复溜**（太溪上2寸）：按揉3分钟，敛汗固表
- **阴郄**（腕横纹上0.5寸）：按揉2分钟，宁心敛汗
- **足三里**：按揉3分钟，健脾固表（气虚加用）

**操作建议**：艾灸复溜、阴郄（气虚/阳虚型）；每穴按揉2分钟，每日2次
