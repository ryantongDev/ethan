# 手脚凉

## 可能辨证方向
1. **阳虚** — 手足冰冷，腰膝冷痛，畏寒喜温，舌淡胖苔白，脉沉弱
2. **血虚寒厥** — 手足厥冷，麻木疼痛，舌淡苔白，脉细欲绝
3. **肝气郁结** — 手足不温，情绪抑郁，胁肋胀闷，舌淡苔白，脉弦
4. **热厥** — 手足厥冷但胸腹灼热，舌红苔黄，脉数（真热假寒）

## 需要追问
- 手脚凉是冰冷还是只是不温？
- 是否从指/趾尖开始还是从根部开始？
- 是否伴有疼痛、麻木？
- 遇情绪变化是否加重？
- 舌象（舌色、苔色苔质）、脉象（若知）
- 是否在温暖环境中仍不缓解？
- 既往是否有糖尿病、血栓、雷诺病等

## 相关方证
| 方剂 | 适应证 | 关键指征 |
|------|--------|----------|
| 四逆汤 | 阳虚寒盛 | 手足冰冷，脉沉微 |
| 当归四逆汤 | 血虚寒厥 | 手足厥寒，脉细欲绝 |
| 柴胡疏肝散 | 肝气郁结 | 手足不温，脉弦 |
| 四逆散 | 热厥（真热假寒） | 胸腹灼热，手足冷，舌红苔黄 |

**⚠️ 警告**：热厥是危重症，指尖冰冷超过肘膝可能，需紧急就医

## 经典依据
- 《伤寒论》"凡厥者，阴阳气不相顺接，便为厥"
- 《金匮要略》"血虚寒厥，脉细欲绝者，当归四逆汤主之"

## 药食同源调理方向
- **当归**（养血活血）：当归6g，大枣3枚，煮水（血虚寒厥）
- **肉桂**（温阳通脉）：肉桂2g，研粉冲服（阳虚，忌阴虚火旺）
- **红花**（活血通络）：红花3g，藏红花0.5g，泡酒外擦（血瘀注意剂量）
- **艾叶**（温经散寒）：艾叶30g，煮水泡手泡脚（每日15分钟）

**禁忌**：热证忌肉桂；阴虚火旺者慎用温热药；糖尿病神经病变者温度感知差，泡脚需低于40℃

## 穴位按摩方向
- **关元**：按揉3分钟，艾灸
- **足三里**：按揉3分钟，艾灸
- **涌泉**（足心）：搓3分钟，温肾助阳
- **太冲**：点按2分钟（肝气郁结加用）

**操作建议**：每晚艾叶水泡脚15分钟（水温≤40℃）；艾灸关元、足三里各5分钟
