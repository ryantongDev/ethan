# Geometry Dash - CrazyGames Submission

A Geometry Dash-style HTML5 game, ready for upload to CrazyGames.

## Files

```
index.html   ← Single-file HTML5 game, no external dependencies
```

## Features
- Canvas 2D rendering with Web Audio API
- CrazyGames SDK V3 (midgame ads on death)
- Bilingual (English/Chinese toggle)
- Difficulty levels: Easy / Normal / Hard
- Score tracking with localStorage

## Controls
- Click / Space / Tap to jump
- After death: click/space/tap to show ad, then restart
